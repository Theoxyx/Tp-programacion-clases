## Descripción
Sistema de biblioteca con tres clases que se relacionan entre sí:
- `Libro` (`libro.py`): título, autor, ISBN y estado (disponible/prestado).
- `Socio` (`socio.py`): nombre, DNI y hasta 3 libros prestados a la vez.
- `Biblioteca` (`biblioteca.py`): guarda libros y socios y coordina los préstamos y devoluciones.

## Cómo ejecutarlo
Hace falta Python 3. Desde la carpeta del proyecto:

```bash
python main.py
```

Se muestran algunos préstamos y devoluciones y el programa termina con `¡Todas las pruebas pasaron!`.
